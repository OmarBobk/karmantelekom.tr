# Benchmark the workflow

1. State the actor, device, primary task, and decision to resolve. Read the target workflow and its branch, permissions, and data constraints. Search for the action and context together, such as assigning existing staff to a retail location.
2. Search the web and open two or three relevant, first-party sources from real products. Look for official help, public demos, or product screenshots for the same task. Start with the closest workflow. For retail branch operations, Shopify POS and Square are useful leads when their specific flow matches.
3. Record the direct URL and the exact interaction each source shows or documents. Label observations as visual evidence, documented workflow, or inference. If a source is inaccessible, use a public substitute or report the gap. If web access is unavailable, label the benchmark pending and any design proposal provisional.
4. Compare the approaches by time and effort to find the main action, clarity of scope, and how they prevent or recover from the most likely mistake. Use actual steps or observations where available. Choose the pattern that fits Karman's users, device, and task frequency. Take access rules and business behavior from Karman.
5. Return a compact handoff with the task, two or three linked findings, one recommended pattern, its main tradeoff, and how to adapt it. State which design decisions still need visual judgment.
